PRESENTATION MODE SETTINGS PREVIEW — 0.5.0 / BUILD 12

Status
This source publication does not include a new release or authorize installation.
Build 12 is installed on Pro1; its physical three-screen verification is pending.
Four-card operation has offline coverage only.

Requirements
• Apple silicon Mac, macOS 14 or newer.
• Compatible DeckLink hardware and Blackmagic Desktop Video for SDI output.
• Extended display/HDMI EDID emulator and Screen Recording permission.
• Playback is progressive 1920×1080 at supported 23.98/24/25/29.97/30/50/59.94/60 timings.

For a separately authorized installation or test
1. Build with: sh Packaging/build-app.sh
2. Use the resulting "Presentation Mode Settings Preview.app". Preserve any
   accepted installation and its preferences before replacing it.
3. Open the app normally. It starts in Production Mode with outputs stopped.
4. Grant Screen Recording access to this app, then quit and reopen it.
5. Select the extended Canva display in Controls.
6. Review the actual Outputs in Setup. Choose Direct or Fill + Key, select an
   eligible Key on the same card, and choose a common supported timing.
7. Apply while outputs are stopped. Apply saves without starting playback.
8. In the agreed hardware test, Canva Mode starts outputs; Production Mode
   stops them and releases DeckLink for ProPresenter. No arming command is needed.

Notes
• Bundle ID: com.wcmedia.PresentationMode.SettingsPreview.
• Ad-hoc signed by default; rebuilds may require Screen Recording access again.
• Companion is off by default. Explicit environment opt-in binds to loopback
  TCP 19876 only, without Bonjour. The production 9876 policy is separate.
• NDI is optional and defaults off for new preview configurations; review the
  saved sender name before enabling it.
• The default profile preserves Largo assignments; review it for another room.
• No Desktop Video profile change or automatic login item is added.
• See README.md and PUBLICATION-VERIFICATION.md for current limits and evidence.
